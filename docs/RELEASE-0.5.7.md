# MediaSail 0.5.7

- 首页可一键复制 `MediaSail 接入.md` 文件，直接粘贴到支持附件粘贴的 Agent；无需手动下载或选择保存位置。
- 下拉保留复制文字，并可修改、保存附件名称。正式 Skill 原件和业务资料保持原样。
- 接入说明提供可直接执行的完整命令，优先使用本机 Skill、按任务查资料，ZIP 仅作备用。
- 每次复制生成独立文件，退出软件后仍可粘贴。复制成功不代表目标 Agent 已接收或已经连接。

已验证 Windows 真实文件剪贴板和独立 Chromium 输入框接收 MD 附件。TRAE、Codex 及资源管理器实际窗口因本轮原生验收工具启动故障未验证；目标客户端不支持文件粘贴时，可使用“复制文字”。不宣称所有 Agent 客户端兼容。

客户端实际兼容情况、截图与升级结果见[验证记录](https://github.com/jerryrenjianxing-sys/MediaSail/blob/main/docs/VERIFICATION-0.5.7.md)。当前为候选验收阶段。

# MediaSail 0.5.3 验证记录

## 问题与变更

0.5.2 在用户本机复制旧库时遇到指向已移除 OpenClaw 安装的插件目录联接点，迁移停在扫描阶段，启动无法继续。此前隔离样本未包含这类真实旧链接，未覆盖该现场。

按用户确认，0.5.3 完全取消文件复制迁移和回退，首次启动直接选库。旧失败任务只保存记录，不执行；新库与旧资料独立。本次升级重新选择一次，后续沿用直接选择记录。

已有库的 `agent-skill` 及 `mediasail` 子目录存在时必须是普通目录，避免选库后才失败或沿联接点写出库外；缺失时允许随包初始化。提交位置前仅对选定的几个受管目录进行临时文件写入探测，失败不改变当前选择。

## Windows 首装与本机修复

全新 Windows 夹具使用真实 NSIS 向导，程序安装在中文空格路径，没有提前写入安装登记或资料库选择。程序目录页与真实安装完成后，首启通过真实“选择资料库”按钮先取消、再选择中文空格目录，发行代码完成验证、初始化、原子提交和重启。测试仅定向原生文件夹选择器的返回值，没有替换初始化或重启实现。[机器记录](evidence/first-install-gui-0.5.3.json)。安装向导至完成观察值 54.567 秒；首启至选库后服务就绪观察值 10.810 秒包含调试观察器、取消选择和重新选择，不能当成纯启动基准。

本机使用 Explorer 原生上下文，先核对旧版无未保存编辑，走软件正常退出；安装器保留 `D:\mediasail`。本次 NSIS 从启动到退出代码 0 用时 50.969 秒。启动选择用户已指定且确认空的 `D:\mediasail data`，库内画像为空、当前画像未选、AitoEarn Cookie 为零，Agent 接口与本机物理目录一致。之后连续两次正常退出并重开，资料库身份与位置均保持。

旧 AppData 工作区和悬空插件联接点仍保留。本次没有递归扫描旧业务资料；本机保留按实际操作范围核对，逐文件不变另在隔离固定样本中验证。旧迁移和选库元数据仅改名留档，安装前定位信息与安装登记备份留在本机恢复记录目录，没有上传账号资料。新库只领用本次安装器基线，SHA-256 与正式候选相同，暂存副本已退役。

程序文件由 838,588,314 字节变为 838,587,260 字节（用户资料不计入）。安装包为 262,989,425 字节，约 250.8 MiB，SHA-256：`5f2a5003fc5fb4a1acc70ad9266230943540844582cecc03b2594131950fe23e`。

## 原登记 0.5.2 升级与覆盖安装

一次性 Windows Runner 先安装哈希固定的官方 0.5.2，保留真实登记，在旧库放入合成画像、成品、草稿、平台会话与旧散资料，同时留下旧插件坏联接点。随后使用正式候选安装包和原更新参数真实安装，没有指定 `/D` 来掩盖路径问题。新版重新选库，旧固定样本的字节及坏链接保持，旧画像、草稿及 Cookie 没有带入；当前安装器基线正确领用。新库正常重启、再次真实覆盖安装后，选择及新合成 Cookie 继续保留。

[完整机器记录](evidence/registered-ready-upgrade-0.5.3.json)、[真实安装进度](images/0.5.3/upgrade-ready-progress.png)、[首次选库](images/0.5.3/upgrade-ready-library-choice.png)、[新库首页](images/0.5.3/upgrade-ready-home.png)。Runner 上观察安装与覆盖安装分别为 339.827 秒及 290.904 秒，包含高频 PowerShell 窗口观察与调度开销；不是更新下载速度或用户本机安装基准。本机同参数的 51.497 秒另列，两个环境不混算。

首装验收初次失败发生在测试观察器过早连接 Electron 的 Windows 调试映射，已仅修复有限重试并重跑通过；安装包没有改变。原升级夹具观察过于频繁，后续诊断改为每 10 秒观察并输出阶段；没有将等待时间当作软件缺陷修改安装包。

旧迁移失败源态的独立真实安装也已通过：旧 failed transaction、旧散资料、旧库及悬空插件联接点同时存在，0.5.3 首启仍进入选库页。真实按钮取消后留页，再选择新空目录，旧固定样本不变且不导入；新库正常重启、再覆盖安装后仍沿用选择及合成登录状态。没有使用真实账号或公开发布。

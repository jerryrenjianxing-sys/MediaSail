# MediaSail 0.5.12（候选）

外部 Agent 可将账号观测直接回存到工作台，缺少浏览器能力时按需使用自动配置的专用 Chromium + BrowserSkill。软件提供背景、工具和成果管理，研究与创作方式仍由 Agent 自主选择。

- 专用浏览器和扩展自动准备、连接；首次按网站流程登录，之后在当前资料库保留状态。没有 CfT 测试发行横幅，正常控制提示及取消入口保留。已有外部浏览器工具可继续使用。
- “账号与数据”和工作台优先展示已保存观测，注明实际取得时间、来源、范围、缺项及证据；刷新不自动登录或启动旧采集器。旧原生登录/采集工具折叠保留，仍使用它自己的独立资料。
- CLI/HTTP 共用观测存储，支持离线回存、重复核对、冲突保护及同口径增长；缺项不补零，晚导入的旧材料不变成最新数据。证据、报告及画像沿用原目录与保存接口。
- 浏览器工具缓存与软件程序分开。关闭 MediaSail、切库、更新不终止已有连接；任务解除保留浏览器，登录配置不随程序替换。浏览器升级前关闭并备份配置，不并发打开或降级读取。
- 首页仍只复制简短 MD；完整 Skill 增加按需浏览器与账号观测资料，不安装到其他 Agent 全局配置，不增加固定工作流。

本版使用隔离资料验收，不修改日常安装、不公开发布内容。详细执行范围及待验收项见 [验证记录](VERIFICATION-0.5.12.md)。正式发布前需完成全部发行门槛；此文件不代表候选已上架。

普通用户只需 Windows x64 Setup。对应浏览器源码分卷、构建材料和 BrowserSkill/依赖源码另放同一 Release 的 Browser Sources 资产，供开发者按需下载，不计入用户安装下载。

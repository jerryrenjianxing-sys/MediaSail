# MediaSail 0.5.4

内容库增加用途分类、搜索、组合筛选和归档信息编辑。软件与外部 Agent 仍使用同一份项目文件，现有目录保持原位，不执行资料迁移。

- 顶部按创作内容、分析报告、参考资料、未分类查看；搜索标题、项目目录、摘要和标签，并按画像、平台、形态、阶段筛选。
- 卡片和项目详情可编辑标题、摘要、用途、形态、阶段、画像、平台和标签；标题修改不会重命名目录。
- 阶段显示为草稿、已就绪、已标记发布；归档标记不代表平台实际发布成功。
- 保存只合并修改字段，保留成品、封面、步骤及扩展数据；外部更新发生冲突时保留编辑，文件损坏或保存失败时明确报错。
- 更新 Agent Skill、业务脚本用途参数及登记接口资料，保持自由选择创作工具。
- 修复筛选零结果后按钮消失，以及空内容库仍引导使用旧内置聊天的提示。

0.5.3 已选择的资料库继续沿用；首页、主题、账号、登录资料、AitoEarn 和更新方式保持原样。新版本不自动给旧项目猜分类，缺少用途的项目在“全部”和“未分类”中可见。

Windows x64 完整安装包、源码、差量索引、更新索引和校验文件随本版本提供。历史 Release 保留；发行包未配置 Windows 代码签名。

测试范围和实际结果见 [0.5.4 验证记录](https://github.com/jerryrenjianxing-sys/MediaSail/blob/main/docs/VERIFICATION-0.5.4.md)。

MediaSail 0.5.0：外部 Agent 接替与轻量化

- 移除内置聊天和OpenClaw。画像、运营分析方法、采集统计和业务工具继续保留，由你熟悉的Agent完成研究、解释、策划与创作。
- 移除通用生图/抠图/配音/剪辑执行器和大型运行环境；专业创作方法保留，Agent自行选择工具。
- 保留账号、内容库、选题、日历、原生发布和AitoEarn草稿流程。平台网页登录使用本机Chrome或Edge；视频请准备现成封面。
- 独立保存画像选择，支持外部Agent更新后的刷新和未保存编辑保护；旧聊天归档可从设置打开。
- 沿用原更新频道。安装时正常卸载旧程序并替换为新版，清除旧大型程序环境，用户数据目录保留。旧GitHub版本与用户自行保存的安装包不删除。

下载 Windows x64 Setup.exe 安装或通过旧版检查更新升级。安装包未配置Windows代码签名；平台账号、登录与真实发布由使用者自行验收。

源码、校验、差量索引和依赖许可随本版本提供。完整验证见仓库 docs/VERIFICATION-0.5.0.md。

# MediaSail 0.5.11 验证记录

状态：开发候选，正式发布尚未完成。需求与审查基线见[实施依据](SPEC-0.5.11.md)。仅隔离数据与安装，不覆盖日常安装及资料库，不使用真实账号公开发布。

## 反馈循环

用户提供的会话仅作本地定位材料，发行不包含原会话、账号、作品正文、浏览器资料或凭据。记录反映：首次已核验账号并抓到部分指标，后续同接口仍缺项，直到临时浏览器探针读取管理页才取得作品；追问本身没有修复采集器。

回归使用独立合成文本与数字，测试位置沿用已确认的 CLI、HTTP、可见界面及隔离真实安装：

- 真实 CLI 加外部浏览器合成响应，旧逻辑返回 posts=null、notes=[]；期望读取延迟列表的测试先失败，修复后读到管理页范围计数及五条已发布内容。原概览 posts 仍未知，粉丝数仍未知，粉丝指数单独保存，报告具体缺项。
- 连接中断先复现失败阶段不清楚，再增加阶段与安全的网络错误码；已有首页计数保留，诊断不回传带凭据的 URL 或浏览器命令行。
- 样本六条被误当覆盖完整，先红后修；调用方可扩大为1—100，返回明确上限、范围、总数及是否还有未覆盖内容。
- HTTP 调用完整 CLI，只模拟外部浏览器进程，旧参数未传入时返回6条而不是9条，先失败再修正。
- 0.5.10 实际打包首页执行界面用例，因缺少采集不完整提示而失败；新版分别显示部分结果、失败、明确空态及旧缓存完整性未知。
- 补测总数仍显示0但卡片已可见的异步冲突：旧实现冒认0，修复后保留未知总数、已有作品及冲突原因。

## 兼容与边界

旧指标、登录三态、数据目录及快照公式继续保留。collection 为附加说明；登录成功不等于采集完成，脚本正常退出也不等于所有字段完整。明确空态读取重点覆盖抖音，其他旧平台列表没有空态证据时按未知处理；B站与公众号原采集器尚未提供此完整性报告时，界面如实标注。

抖音作品页总数解释为当前管理页筛选范围，不承诺全量公开作品。未覆盖、加载和解析问题按分项记录，精确粉丝数与粉丝指数不混用。部分已核验计数沿用原快照逻辑，缺失保留null，全部失败不登记正常计数样本。

Skill 提供候选来源、工具与资料锁用法，Agent 自主决定补查深度。连接仍轻量，不自动全平台采集，不增加每轮流程或平台执行链。分析稿区分观察、推断、假设及适用账号、窗口、单位；不是强制报告模板。

源码检查通过：117 Node、110 Python（原有文件链接权限限制跳过1项）、前端类型及构建、43条接口说明、固定上游补丁复现。打包744个有效载荷文件哈希及干净工作区初始化通过；[发布实现提交CI](https://github.com/jerryrenjianxing-sys/MediaSail/actions/runs/41605816299)通过。

随包 Python 和本机真实 Chrome 执行合成网络页面：延迟列表、明确空态、连接中断3组通过，见[真实浏览器记录](evidence/collection-browser-0.5.11.json)。实际浏览器执行页面文字和JS，模拟仅在平台HTTP边界，没有真实账号。早期测试仅替换HOME/USERPROFILE的环境与真实Windows环境不一致，导致测试启动超时；去掉这项多余模拟，继续显式隔离浏览器资料目录后通过，未据此改动产品浏览器选择或宣称修复另一台电脑的启动问题。

[打包界面](evidence/collection-ui-0.5.11.json)通过：部分结果/缺项和指数区分、读取失败保留数据、刷新失败保留旧结果、明确空态、旧结果完整性未知，及[浅色](images/0.5.11/collection-light.png)/[深色](images/0.5.11/collection-dark.png)显示。[双轴审查](REVIEW-0.5.11.md)复审通过；[证据提交CI](https://github.com/jerryrenjianxing-sys/MediaSail/actions/runs/41606499160)通过。不把这些合成反馈写成真实账号采集验收。

## 首轮审查修正

Standards 发现管理页筛选总数混入旧 posts 增长；修正为只在 notesCoverage.total 保存管理页总数，旧 posts 保持概览口径。Spec 发现占位0提前作为空态、重绘丢失部分作品、知乎粉丝子页被错误归为首页来源；分别补反馈用例再修复。计数0需独立空态文案支持，已读部分作为失败后的保留结果，来源随实际读取页面记录。发行候选包已按修正后的实现重新构建，并复验实际浏览器及打包界面。

## 独立 Agent 与成果回存

新的独立上下文 Agent 只从合成的 `MediaSail 接入.md` 进入，用户任务仅为“帮我分析一下抖音”，另说明这是离线合成验收、不访问真实平台。没有告知它预期的缺项、作品数或应选工具。

Agent 自行读取完整 Skill、画像和项目资料，发现初次只返回6/9条后，继续读取同项目管理页快照；交叉核对原6条，补得另外3条，自选本地工具计算，并使用现有登记脚本回存报告。不需要用户再次下达采集指令。它保留了未知粉丝数、原概览作品数及不足以判断增长、推荐原因和转化归因的边界，没有改写原始采集结果。

随后独立观察脚本重新打开实际打包程序，核对报告文件、HTTP内容、分类/画像/成品路径、原始证据副本字节及[内容库页面](images/0.5.11/collection-agent.png)，均通过。详见[Agent验收记录](evidence/collection-agent-0.5.11.json)。整项研究与回存耗时454.1秒，不是连接耗时承诺；这是本地既有证据补查，实时浏览器采集另由前述合成网络页面验证。

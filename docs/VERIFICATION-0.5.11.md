# MediaSail 0.5.11 验证记录

状态：开发候选，正式发布尚未完成。需求与审查基线见[实施依据](SPEC-0.5.11.md)。仅隔离数据与安装，不覆盖日常安装及资料库，不使用真实账号公开发布。

## 反馈循环

用户提供的会话仅作本地定位材料，发行不包含原会话、账号、作品正文、浏览器资料或凭据。记录反映：首次已核验账号并抓到部分指标，后续同接口仍缺项，直到临时浏览器探针读取管理页才取得作品；追问本身没有修复采集器。

回归使用独立合成文本与数字，测试位置沿用已确认的 CLI、HTTP、可见界面及隔离真实安装：

- 真实 CLI 加外部浏览器合成响应，旧逻辑返回 posts=null、notes=[]；期望读取延迟列表的测试先失败，修复后读到作品总数及五条已发布内容。粉丝数仍未知，粉丝指数单独保存，报告具体缺项。
- 连接中断先复现失败阶段不清楚，再增加阶段与安全的网络错误码；已有首页计数保留，诊断不回传带凭据的 URL 或浏览器命令行。
- 样本六条被误当覆盖完整，先红后修；调用方可扩大为1—100，返回明确上限、范围、总数及是否还有未覆盖内容。
- HTTP 调用完整 CLI，只模拟外部浏览器进程，旧参数未传入时返回6条而不是9条，先失败再修正。
- 0.5.10 实际打包首页执行界面用例，因缺少采集不完整提示而失败；新版分别显示部分结果、失败、明确空态及旧缓存完整性未知。
- 补测总数仍显示0但卡片已可见的异步冲突：旧实现冒认0，修复后保留未知总数、已有作品及冲突原因。

## 兼容与边界

旧指标、登录三态、数据目录及快照公式继续保留。collection 为附加说明；登录成功不等于采集完成，脚本正常退出也不等于所有字段完整。明确空态读取重点覆盖抖音，其他旧平台列表没有空态证据时按未知处理；B站与公众号原采集器尚未提供此完整性报告时，界面如实标注。

抖音作品页总数解释为当前管理页筛选范围，不承诺全量公开作品。未覆盖、加载和解析问题按分项记录，精确粉丝数与粉丝指数不混用。部分已核验计数沿用原快照逻辑，缺失保留null，全部失败不登记正常计数样本。

Skill 提供候选来源、工具与资料锁用法，Agent 自主决定补查深度。连接仍轻量，不自动全平台采集，不增加每轮流程或平台执行链。分析稿区分观察、推断、假设及适用账号、窗口、单位；不是强制报告模板。

源码检查、真实浏览器、打包界面、双轴审查、独立 Agent 及真实隔离升级结果将在完成后补齐；不把合成反馈写成真实账号采集验收。

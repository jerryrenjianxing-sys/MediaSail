MediaSail 0.5.1：修复旧版更新旁装与旧程序未清理

- 修复部分旧安装缺少 Windows 安装登记时，更新另装到默认目录、留下原位置旧程序的问题。
- 对已核验的官方 0.4.3，更新安装器从本机连接资料确认原位置，核对程序、卸载器及应用资源的官方 SHA256，进入安装阶段才临时恢复本软件登记，继续调用原卸载器。
- 卸载失败会停止更新并恢复原登记状态，保留数据和日志；不通过递归删除旧目录绕过失败。
- 新客户端更新时明确传递自身安装位置。沿用 0.5.0 的外部 Agent、画像、分析、内容库和发布功能，数据目录与登录资料位置保持不变。

从软件内检查更新，或下载 Windows x64 Setup.exe。此版本不自动删除其他目录中的手动副本，也不删除用户自行保存的安装包。无法核验旧程序时会停止，并在用户数据目录 logs 中记录原因。

源码、差量索引、更新索引和 SHA256 校验文件随本版本提供。验证记录见仓库 docs/VERIFICATION-0.5.1.md。

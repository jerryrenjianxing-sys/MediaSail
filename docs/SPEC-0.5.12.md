# MediaSail 0.5.12：内置专用浏览器与 BrowserSkill

需求来源：用户确认的同名实施计划。审查基线 `v0.5.11`（`1bb16b42b4aa29bb1f53b83f336f87562c208341`）。本文件是验收要求，不是通过声明。此前 agent-browser、个人 Edge/Chrome 调试、商店扩展安装及 CfT 发行方案已被取代；研究和失败记录保留。

## 浏览器与自动配置

- 内置可见的 ungoogled-chromium Windows x64 便携版 `156.0.8078.73-1.1`，原仓库归档 SHA-256 `360406931fb55b04ac276bcf409511bd86e4e67e6950029fc45ca5ca63443090`。不发行 CfT。实际组件许可、署名和对应源码义务通过后才发行；完整窗口无“仅用于测试”横幅，保留交互授权提示，不改变企业策略或静默调试设置。
- 内置 BrowserSkill 0.4.1 源码适配构建，固定原始提交、构建标识、扩展身份、补丁与许可证。禁止启动同步其他 Agent Skill 和自行升级；安装包不添加独立 Node/npm、额外模型环境。
- 软件自动准备浏览器、扩展、daemon 与握手。用户只完成网站首次登录或平台要求的重新验证，不安装扩展、不寻找调试设置、不运行命令。不复制个人浏览器或原型的 Cookie，不用较旧浏览器打开较新配置。
- 工具校验后在当前资料库版本缓存临时复制、清单校验、原子启用，相同内容复用，不覆盖在用版本。准备失败保留可用文件并允许重试；首版不自动清理旧缓存。
- 登录配置固定在资料库 `runtime/browser/`，与程序/版本缓存分开。各库独立工具组、私有连接信息和端口，daemon 与固定扩展核对同组身份。端口占用不接管其他程序。
- 浏览器和 daemon 独立运行。关闭 MediaSail、升级和切库不终止已有会话。浏览器仍运行时继续使用原工具组，正常关闭后才启用新版。禁止同一配置由两个版本同时打开或静默降级；浏览器升级前在关闭状态备份并核验配置，失败保留原件和日志。

## Interface 与 Agent 文档

- PowerShell 5.1 入口支持 `prepare/status/connect/run/disconnect`，不依赖业务服务、安装目录 Python 或全局 Node。现有 helper 在 Python 检查前分派 browser 命令。
- prepare/status 不启动浏览器；connect 自动准备、启动和连接，返回绑定原库、版本与浏览器实例的 sessionRef 及固定缓存入口。disconnect 只结束对应任务连接，保留浏览器。
- 新连接读取最新发现资料；旧回执仍可操作原库。run 失效明确报错，不自动换浏览器、换账号或重放结果不明的操作。
- 发现文件增加可选 browserTools 路径/版本/说明，不公开凭据。轻量 check 无浏览器前置条件；首页只复制简短 MD，完整 Skill 按需介绍工具连接、网站登录、后台权限、范围、证据与回存。
- 外部 Agent 已有能力时直接复用。无固定业务链、每轮检查、全局 Skill 安装、自有 MCP 或远程命令服务；个人元数据保留 `allow_implicit_invocation: false`。

## 已保存账号数据与成果

- ObservationStore 共用 CLI/HTTP，POST/GET `/api/account-observations`、GET `/{id}` 及 helper `observations register/list/show`，支持服务关闭时本地操作。记录在 `workspace/outputs/_analytics/observations/`，一条 JSON 一个文件。
- 保留原指标、作品、collection，补充编号、平台、实际取得时间、导入时间、生产与业务来源、身份依据、可未知的账号/画像、字段口径及证据引用。零不作缺失；缺项仍可保存和写报告。外部观测不改变旧登录状态或 whoami 缓存。
- 规范化内容 SHA-256 自动编号，同编号同内容复用，不同内容冲突。CLI/HTTP 跨进程锁、落盘、原子提交；损坏记录保留并报错，不隐藏正常记录。失败不清空旧有效数据，旧材料晚导入不变成最新。
- 仅同平台、稳定账号、业务来源和字段口径可比时使用原增长公式；原因未知明确说明。与旧采集历史分别保存比较，不按昵称合并。
- 账号与数据页/工作台默认展示保存观测，提供平台、账号、来源、观测选择；首次最近有效，刷新保留选择，不暗换账号。打开、恢复、筛选不自动调用旧 whoami 或旧采集器。旧接口、资料、登录及结果折叠兼容；“刷新资料”只是重读。
- 证据/报告沿现有项目，画像沿现有保存接口；分别核对回执，失败只补保存，不重新取数。界面重读不覆盖未保存编辑。软件暂时不可用时，原库材料保留，恢复后向同库登记。
- 首页、MD 复制、主题、资料库、AitoEarn、安装标识与更新频道保持现状。

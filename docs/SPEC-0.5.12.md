# MediaSail 0.5.12：真实浏览器协作与账号观测

需求来源：用户已确认的《MediaSail 0.5.12：真实浏览器协作与账号数据回存》。审查基线为 `v0.5.11`（`1bb16b42b4aa29bb1f53b83f336f87562c208341`）。

## 行为与兼容

- 外部 Agent 优先复用自己的浏览器工具和用户真实会话；缺少能力时才使用可选备用工具。业务方法不绑定取数工具或固定执行链。
- 备用组件固定 Playwright CLI 0.1.23 及锁定 JS 依赖，复用已有私有 Node v24.21.0，通过官方扩展连接 Edge、Chrome。无全局 Node/npm、无额外 Chromium 的双浏览器实际连接是发行门槛。扩展安装确认与首次授权沿浏览器原生流程；准备工具、检查状态和说明步骤可由 Agent 代劳。
- 备用运行组件按内容指纹部署到所选资料库 `runtime/cache/browser-tool/`，校验后原子启用，不覆盖在用版本。日志、输出及注册状态留在本库，真实浏览器发现继续使用用户环境。
- 每个备用会话返回独立 sessionRef，绑定资料库身份及工具缓存。退出、升级和切库不终止外部 Agent 会话；新会话采用最新发现信息，旧会话仍属于原库。解除连接保留浏览器。
- 保留短 MD 接入卡、完整 Skill、发现文件及轻量 check。browserTool 可为空，不作为普通接入成功条件；不增加服务端命令执行或 Agent 全局配置。
- 账号观测独立保存在 `workspace/outputs/_analytics/observations/`。CLI 与 HTTP 使用同一个 Module，支持离线登记、查询及读取。
- 观测保留实际取得时间、导入时间、平台、业务来源、生产来源、可未知的稳定账号和画像、原指标/作品/collection、口径及证据引用。缺项可保存，零与缺失分开；不改变旧登录状态。
- 自动编号采用规范化内容 SHA-256；同编号同内容复用，不同内容冲突。跨进程串行、落盘及同目录原子提交；损坏记录保留并明确报告，不隐藏其他正常记录。
- 新旧数据分开比较。仅同平台、稳定账号、业务来源及字段口径可比时复用原增长公式；未知时给出原因，不伪造 verified。
- 账号页为“账号与数据”，默认展示保存的观测；工作台选择平台、账号、来源和观测，刷新保留选择。页面打开、恢复及筛选不调用旧 whoami/采集。原生工具和旧结果折叠保留，不自动认领或导入。
- 回存数据、证据和报告分别核对。失败只补保存，不重新取数；服务暂不可用时保留原库材料。遵守现有编辑保护。
- 首页、MD 复制、主题、资料库、AitoEarn、安装标识及 GitHub 更新频道沿用。旧采集器主动使用时仍需自己的工具登录。

## 测试位置与发行门槛

1. CLI 与 HTTP：真实文件读写、缺项/零、重复/冲突、并发、原子写入失败、损坏记录、实际时间排序、账号与口径可比、跨库误投。仅外部网络/浏览器和故障注入可模拟。
2. 备用 CLI 与真实浏览器：Edge/Chrome 首连复连、原生用户资料、解除连接、断线、中文空格路径、缓存并发和中断；无全局 Node/npm 或额外 Chromium。
3. 可见界面与独立 Agent：默认不启动旧浏览器；旧工具未登录时可显示观测；读 MD 找到方法，登记合成观测、分析和报告，刷新可见，草稿保留。首个真实只读取数业务为抖音，再用另一已有工具证明业务回存不绑定备用工具。
4. 安装器：隔离 `0.5.11 → 0.5.12` 升级和两次重启，再覆盖重装 0.5.12，缓存中的 Agent 会话继续工作。保留资料及登录信息，不改日常安装。
5. 统一源码检查、前端构建、接口一致性、补丁复现；按 matt 分别完成 Standards 与 Spec 审查。
6. 构建安装包、源码包、更新索引、差量索引、校验文件；草稿资产核验及候选验收通过后再发布最新版，保留历史。报告安装包和首次工具缓存实际占用，不把未验证能力标为通过。

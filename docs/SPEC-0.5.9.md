# MediaSail 0.5.9：首页单一复制按钮

用户要求移除首页「修改文件名」及影响外观的展开键。首页保留一个普通「复制 Skill 文件」按钮，固定生成 `MediaSail 接入.md`，复制成功、失败原因和重试沿用现有行为。删除改名弹窗、编辑状态、菜单及专属样式，恢复双按钮一致的外形与响应布局。

不再读取旧自定义文件名；旧偏好及已生成的附件原位保留，不做数据清理。桌面复制接口、快照持久保存、短接入卡、完整Skill与其他业务功能保持现状。普通网页版仍提示使用桌面版。

沿用已确认的可见首页、文件剪贴板及隔离安装验证边界，调整现有验证脚本：旧自定义偏好存在时仍复制固定名称；验证无菜单/弹窗、重复复制、失败重试、重启、浅深色及窄窗口。统一源码检查、补丁复现、双轴审查以已发布v0.5.8为基线。构建0.5.9，候选通过隔离0.5.8 → 0.5.9真实升级后发布原GitHub频道，保留旧版本，不操作日常安装及资料库。

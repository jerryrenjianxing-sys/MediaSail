# MediaSail 0.5.13

本版修复外部 Agent 接入时的后台启动与代理环境兼容问题，完善按任务推进、必要登录、取数和回存说明。

- 新建内置浏览器连接交由运行中的 MediaSail 桌面进程启动；WorkBuddy 等宿主只发送本机连接请求，不再负责创建独立后台进程。
- Windows 代理变量按系统大小写规则合并，优先大写键，保留代理并补充本机绕过，不修改外部 Agent 环境。
- 连接有请求编号与原结果查询，重复请求复用原回执；结果不明先核对，不盲目重试。
- 「旧采集工具」采用独立抽屉，保留主页面宽度、筛选、滚动位置和未保存编辑。
- Skill 说明 Agent 自主准备工具与网站登录，区分接入、连接和登录状态；补齐任务入口及 UTF-8 调用示例。
- 修复观测中的报告/证据文件链接被当成文件夹的问题，直接打开文件预览，失效链接明确提示。

沿用现有资料库、账号观测、画像与内容格式。Chromium、BrowserSkill 二进制及许可版本保持 0.5.12 已核验版本；浏览器缓存新增修复后的辅助入口，不覆盖在用缓存或网站登录配置。

候选验收进度见 [验证记录](VERIFICATION-0.5.13.md)。正式发布前需完成实际宿主、打包、隔离升级和资产核验。

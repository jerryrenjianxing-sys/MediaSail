# MediaSail 0.5.13：Agent 优先接入与浏览器可靠性修复

需求为用户于 2026-11-05 确认的同名实施计划；审查基线 v0.5.12。使用隔离安装及资料库，不改日常 D:\mediasail、D:\mediasail data 或个人创作偏好。

## 浏览器与连接

保留 prepare/status/connect/run/disconnect；prepare/status 不启动浏览器，connect 请求桌面主进程启动浏览器和 daemon。新建连接要求软件在线，已有原缓存回执离线可用。命名管道 schema 1 只支持连接和查询该次结果；公开描述不含凭据，私有凭据限定当前用户，校验实例、库和固定操作，拒绝任意程序/路径/命令。编号请求幂等，超时查原结果；不自动退回 Agent 启动后台进程。

新回执使用修复后的缓存入口，工具组仍绑定原库和原版本。准备期间检查退出/安装/切库，已建立工具组不归业务服务生命周期管理。Win32 显式环境块修复原始大小写键冲突，代理冲突大写优先，保留代理并补本机绕过，不改宿主环境。

## 页面与指导

现行界面及说明改称旧采集工具，独立抽屉及内部滚动，主区尺寸/滚动/筛选不因开关改变；关闭、遮罩、Esc 共用未保存保护并还焦。工具、资料、浏览器、网站登录分别说明实际状态。开场介绍能力和必要登录，已有任务直接推进，不让用户选择技术路线。

Skill 补任务入口和按需资料，保留专业知识、Agent 工具选择自由及个人 allow_implicit_invocation:false。区分专用浏览器和旧工具登录资料及核验流程；AitoEarn 按实际能力与当次授权操作，不统一写为只能用户执行；个人抖音发布偏好保持。JSON UTF-8 明确，Windows 示例中文读写一致。

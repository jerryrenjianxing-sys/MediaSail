# 浏览器协作的按需接入与状态说明

研究日期：2026-11-05。范围：源码与官方文档，只读研究；没有操作真实账号、安装工具或修改产品。本文是设计建议，不代表备用连接组件或账号观测登记已经实现。

## 推荐体验

沿用首页的短 `MediaSail 接入.md`。外部 Agent 阅读完整 Skill 后，根据当前任务和自己已有的能力决定是否使用浏览器。已有工具且已连接时直接复用；已有工具尚未连接时沿用该工具的连接办法；仅缺少可执行工具时才查软件提供的备用连接说明。单纯读取画像、创作或离线计算不需要先连接浏览器。

软件提供一个跨 Edge/Chrome 的可选执行组件及说明，比只提供一份通用 Browser Skill 更完整；Skill 是业务协作与发现资料，执行组件才负责浏览器连接。具体组件与依赖由另一份选型研究核对。它是备用能力，不成为外部 Agent 的全局必装依赖。

## 五种状态分别解释

| 状态 | 能说明什么 | 不能据此推断什么 |
| --- | --- | --- |
| Agent 有可执行工具 | 能调用浏览器工具、电脑操作工具或本机命令 | 不能推断已连接任何浏览器 |
| 浏览器已连接 | 能读取某个已授权实例或标签页 | 不能推断抖音等网站已经登录 |
| 网站会话可用 | 在具体网站的当前会话中取得相应登录证据 | 不能推断另一个站点或软件私有会话也已登录 |
| 创作者页面可访问 | 能读取对应账号的后台页面与可见数据 | 不能推断具备所有指标、全部历史或发布权限 |
| 保存了一次账号观测 | 某时从某账号、来源和范围取得的数据 | 不能推断浏览器现在仍在线或网站会话永久有效 |

当前 `mediasail.py check` 的 `ok` 只代表 MediaSail 本地服务、身份和资料/工具路径就绪，应继续保持这个含义。浏览器不是所有 MediaSail 任务的前置条件。[实现：连接检查](../../agent-skill/mediasail/scripts/mediasail.py)

## 现有接入可复用的部分

- 短 MD 已经提供发现入口、本机完整 Skill、复制时资料库和画像快照、可执行的轻量连接命令。引导继续通过最新发现信息取得当前路径，不记死端口或旧库。[实现：接入卡](../../bridge/agent_skill.py)
- `agent-connection.json` 已提供 `instanceId`、`libraryId`、`skillDir`、`workspace`、`outputs`、`tools`、业务 Python 等非凭据信息。可按实际选型补充备用工具的命令、锁定版本和参考文档位置；这些字段可为空。浏览器实例与标签页连接仍由所选工具管理，无需新增多 Agent 全局任务状态。[实现：发现信息](../../desktop/agent-connection.cjs)
- 项目报告、证据与成品继续使用 `outputs/<项目>/`、`assets/` 和 `.easel.json`；画像保存继续使用已有 revision。无需第二份同步工作区。[现有回存资料](../../agent-skill/mediasail/references/outputs.md)

## Skill 的组织

主 Skill 只增加条件明确的指针，例如：“需要当前网页资料、浏览器未连接或现有浏览器工具不可用时，查阅浏览器协作资料；已有可用能力可直接沿用。”

按需参考资料在一处说明：

- 当前平台的主页、创作者后台和所需账号权限如何辨认。
- 现有工具优先；备用组件在哪里、实际支持的连接方式与启动条件。
- 如何引导用户完成首次浏览器连接、网站原生登录和需要人的验证步骤。
- 取数时辨认账号、指标标签、单位、时间窗口、样本覆盖及缺项原因。
- 证据、观测和报告保存到当前资料库的实际位置，如何读回核对。
- 断线、标签页关闭、网站退出及权限不足分别如何描述。

工具命令从锁定版本的 `--help` 或随包原始资料查阅，避免把全部命令重复抄进主 Skill。保留个人 Skill 的 `allow_implicit_invocation: false`。按需查阅及单一权威出处符合项目指定的 matt `writing-for-agents` 方法；不把浏览器检查改成每轮仪式。[开发约定](../DEVELOPMENT.md)

## 首次协作与恢复

引导按实际缺口出现，而不是统一执行一条登录流水线：

- 已有工具且已连接：简短反馈找到目标标签页，继续用户任务。
- 有工具但未连接：沿用它的连接入口，说明需要用户选择或授权的具体浏览器/标签页。
- 没有浏览器工具但能运行本机命令：提供备用执行组件的实际路径与说明，用户完成初次浏览器侧连接后即可调用。
- 只有远程聊天、没有本机执行能力：明确当前能力缺口，不重复访问远端自己的 localhost。
- 浏览器已连接、网站要求登录：用户在原生网页完成登录或交互验证，随后继续读数。该状态不称为“浏览器工具连接失败”。

中断后先利用工具已有的连接恢复能力，重新确认实际目标页和账号；已保存的观测、证据和报告保持可读。软件退出只结束自身启动的组件，连接用户或 Agent 管理的现有浏览器时采用解除连接，保留浏览器窗口。具体 detach/close 语义须按锁定工具验收。

用户自行原生登录可以减少截图二维码、转交验证码和重新启动浏览器的环节；网站会话失效、后台权限、交互验证、网络和连接授权仍可能中断任务，不能承诺永不重新登录。

## CLI 优先与 MCP 可选

面向能执行本机命令的 Agent，备用 CLI 可以通过路径按需调用；不要求先写入每个 Agent 的全局配置。仅支持 MCP 的客户端可复用相同底层能力的 MCP 入口，但其配置与权限接入是另外一项准备，不能凭一份 MD 宣称已经安装。

微软官方 CLI 当前文档提供 attach 的扩展/CDP方式及 detach，后者保留外部浏览器运行；它要求 Node.js 18+。官方 MCP 也支持扩展连接现有 Edge/Chrome 标签页和登录会话，并要求 Node.js 与 MCP 客户端。因此“CLI+Skill”减少接入配置，并不自动消除运行依赖。实际发行应固定版本、验证现有系统浏览器路径；文档中的 `@latest` 示例不直接作为安装包的依赖锁。[官方 CLI](https://github.com/microsoft/playwright-cli#open-parameters)、[CLI要求与定位](https://github.com/microsoft/playwright-cli#playwright-cli-vs-playwright-mcp)、[官方MCP扩展](https://github.com/microsoft/playwright-mcp#browser-extension)

## 软件页面需要的衔接

当前账号页与工作台会后台 `verifyStale → whoami`，检查的是软件私有浏览器资料；现有工作台的当前数据来自 `easel_analytics`，采集按钮又会执行旧采集器。外部 Agent 观测不能继续被这份会话的校验结果控制。[账号页](../../vendor/easel/web/frontend/src/components/AccountsPage.tsx)、[工作台](../../vendor/easel/web/frontend/src/components/DashboardPage.tsx)

建议主要展示“最近数据：账号/编号、来源、实际取得时间、范围、完整性、缺项原因”，提供证据与报告入口。现有原生登录、校验、采集放在含义明确的工具区域。用户主动使用旧采集器时，需要其自身有效登录资料；有效资料可复用，不是每次扫码。Agent 路径不以旧采集器登录为前置条件。

需要补薄的账号观测登记/读取 Module，使工作台可读取 Agent 回存结果；单纯写报告目前可进内容库，直接写旧 JSONL 不会自然更新当前指标卡。外部观测与旧会话的实时验证分开记录，身份或口径未知时仍可保存展示，只解释不可自动比较的原因。[现有账号观测与口径](../../agent-skill/mediasail/references/context.md)

## 最小验收

1. 有现成工具且已连 Edge/Chrome 时，无额外安装和重复连接提示。
2. 有现成工具但尚未连接时，只引导补连接，不误导为需要安装第二个工具。
3. 缺浏览器工具的本机 Agent 能按随包路径使用备用组件，选择既有浏览器/标签页；初次浏览器侧连接步骤明确。
4. 工具连接成功、网站未登录、后台无权限、数据缺项四种情形有不同说明。
5. 旧采集器保持未登录，Agent 仍可在原生浏览器读取、登记观测，并在工作台和内容库看到结果。
6. 同名不同账号、主页和后台不同范围、累计和近7日不混成一条增长历史。
7. 断线或浏览器退出后原有证据与报告保留；重连按当前页和账号继续，不凭历史记录显示永久在线。
8. 软件重启、切库和端口变化后重新从发现入口定位；界面未保存编辑不被 Agent 回存覆盖。
9. 结束备用连接或退出 MediaSail 不关闭用户管理的 Edge/Chrome。
10. 用两种已有浏览器工具完成相同回存验收，证明业务登记与工具无关；该选择只用于测试，不变成产品必选工具。

本轮主线程通过已有浏览器工具，在同一 Edge 用户配置的新标签中打开抖音创作者后台，无需再次扫码；通过可见页面的可访问性内容读到了明确标注的近7日统计、精确粉丝数、净增粉丝及最新作品指标。没有调用旧采集器、复制 Cookie 或执行发布。此处匿名记录能力范围，不记录真实账号和数值。

稳定账号编号、作品分页、评论、网络响应及回存尚未验证，开源备用组件也尚未运行验收；不能据此宣称全部取数或上述拟新增闭环已经通过。CLI 的具体稳定版本与依赖选型以本轮独立选型研究的最新结果为准。主线程已只读执行版本核对，确认本地 Playwright 私有 Node 为 v24.21.0，但尚未用它运行新的备用 CLI，因此该环境复用仍需实际验收。

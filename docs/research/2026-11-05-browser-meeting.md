# MediaSail 浏览器备用连接讨论

日期：2026-11-05，Asia/Shanghai。状态：研究与设计建议，尚未修改产品或发行新版本。按项目指定的 matt research、codebase-design 与按需 Agent 文档方法，由独立子任务研究取数能力、工具选型和接入引导；主线程核对当前源码、官方资料及下述只读实测。

## 推荐决定

采用一份通用浏览器协作资料，加一个覆盖 Edge/Chrome 的可选备用执行组件。Agent 自己已有可用工具时优先沿用；已有工具但未连接时先使用原工具的连接办法；只有真实缺少执行能力时才查备用组件。它不成为所有 Agent 的必装依赖，也不成为离线画像、创作或计算任务的前置条件。

首选待验证组合为微软 Playwright CLI 与官方 Playwright Extension。Chrome/Edge 共用主体，渠道、用户配置及安装授权分别核对，不开发两套独立取数流程。MCP 可以作为需要该入口的客户端的可选接入，不自动配置其他 Agent 的全局环境。候选版本、源码依据与发布依赖见[备用工具研究](2026-11-05-browser-fallbacks.md)。

该研究核对的已发行 CLI 为0.1.23，直接依赖的 Playwright/Core 是1.65.0-alpha-2026-10-30；不能因顶层CLI已发行就称整套依赖稳定，也不能直接替换现有业务Playwright。当前商店扩展与CLI依赖提交中的扩展版本不同，真实配对、运行时复用与连接恢复是正式集成前的验收条件，不能只依据官网 main 的示例交付。

Skill 是用途、发现位置、命令资料和业务含义的说明；实际执行工具负责连接与页面操作，二者不能互相替代。产品不规定 Agent 必须采用备用组件、某种浏览器协议或固定取数顺序。

## 本轮新增实测

主线程复用当前 Agent 已具备的 Edge 扩展连接，在相同用户配置中新建抖音创作者后台首页。页面初始显示加载，随后出现当前账号信息、精确粉丝数、明确起止日期的近7日账号指标、净增粉丝及最新作品互动。全程未要求重新扫码，没有调用 MediaSail 旧采集器，没有复制 Cookie 或执行发布。原有抖音主页标签未被改动。

这说明本机当前会话不仅可读主页，也能读取该创作者后台的私有概览。它不证明其他账号均无需后台登录，也不证明分页、评论全量、网络响应、内部稳定账号编号、成品回存或候选开源备用组件已通过验收。实际账号、数值、页面全文与截图不写入本研究文件。

主线程还只读执行了当前构建环境中业务 Playwright 私有 `driver/node.exe --version`，返回 v24.21.0；锁定业务依赖为 Playwright 1.63.0。该 Node 可执行文件为93,580,104字节，已是现有业务环境的一部分。它是复用运行时的候选，不代表新的 CLI 已运行或发行封装已验证；不要为了新工具静默替换旧业务运行时。Electron Node 的复用同样需另行验证。

## 可以取得什么

| 数据 | 当前判断 |
| --- | --- |
| 页面概览、已显示的正文、列表 | 真实浏览器可提供结构化读取或视觉读取；本轮已证实抖音主页及后台概览 |
| 当前账号后台私有指标 | 当前会话和角色确有权限时可读；不能仅凭主站已登录推断后台权限 |
| 作品管理与历史 | 按实际筛选、分页和加载取得，记录范围；不能把当前可见样本说成全部 |
| 评论、图表、细粒度指标 | 可能需要展开、下载或网络响应能力；不同 Agent 工具并不等价，需要专项验收 |
| 增长、复盘及业务计算 | 浏览器取得输入后继续复用 MediaSail 方法和脚本，不让浏览器组件承担业务定义 |

完整能力、现有脚本依据和验收矩阵见[取数能力研究](2026-11-05-browser-capabilities.md)。

## 接入引导

| Agent 的实际情况 | 接入建议 |
| --- | --- |
| 有工具且已连接目标浏览器 | 直接沿用，简短反馈后继续任务 |
| 有工具但尚未连接 | 按原工具的说明引导连接，无需再准备第二套工具 |
| 无浏览器工具，但能运行本机命令 | 按发现资料里的路径调用备用 CLI，用户完成所需的浏览器侧安装、选择和授权 |
| 工具已连接，但网站会话失效 | 用户在对应原生网页登录或完成交互验证，不冒认工具连接失败 |
| 无本机执行能力的远程聊天环境 | 明确能力缺口；MD文件不能凭空提供本机控制 |

首页继续复制短 `MediaSail 接入.md`。首次协作按实际缺口给简短引导；完整接入、恢复、平台入口和取数说明按需阅读。不增加每轮检查，不要求与当前任务无关的浏览器连接，也不把浏览器状态加入既有 MediaSail 轻量连接成功的必要条件。

安装过不等于当前连接仍有效；某浏览器配置已连接不等于其他配置也已连接。初次连接和后续授权行为以锁定工具及浏览器的实际规则为准，不承诺永久免确认。详见[按需引导研究](2026-11-05-browser-onboarding.md)。

## 回存与旧采集器

浏览器工具只解决网页访问。首个产品切片还需薄的账号观测登记与读取能力，让指标卡使用已保存的 Agent 观测，而不自动再调用旧采集器。报告和证据继续使用现有项目目录、素材区与元数据；稳定经验按任务更新现有画像。

观测保留平台、稳定账号编号或未知说明、实际取得时间、业务来源、原指标含义/单位/窗口、覆盖范围、缺项原因和证据引用。数据不全也可保存展示；缺失不补零。重复登记不重复累计，写入失败保留原数据。增长仅在账号和口径可比时计算，旧历史不自动并入。

旧采集器仍使用软件自己的平台资料。Agent 在真实浏览器直接取数时无需先为旧工具登录；主动选用旧采集/发布能力时，才要求其自身有效登录资料，已有登录未失效就可沿用。旧 whoami 的结果不控制 Agent 观测是否展示，也不把导入数据当作旧工具当前登录成功。

## 原生登录的收益与边界

原生登录能减少软件截取二维码、转交验证码、反复启动与重新打开浏览器等额外环节。网站登录过期、后台权限不足、平台交互验证、网络、页面变化和扩展连接断开依然可能发生。目标是减少代办环节、明确失败发生在哪一层并保留已得资料，不能保证永不登录失败。

## 开发前应验证的切片

以真实已登录 Edge/Chrome 和锁定备用组件验证：缺浏览器工具的本机 Agent 能按路径执行；能连接正确配置和标签；旧采集器保持未登录；取得后台概览与指定范围作品；登记后工作台、证据和报告可见；重启可读；解除连接不关闭用户浏览器。再换一种已有工具完成相同回存，以确认业务能力未绑定备用工具。

同步覆盖已有工具不重复安装、断开恢复、同名换号、部分缺项、窗口口径、重复回存与未保存编辑保护。这些是验收案例，不是用户 Agent 每轮的固定执行链。

# MediaSail 0.5.7：复制 Skill 文件与简化接入

用户于本轮批准以下实施与验收：

- 首页主按钮为“复制 Skill 文件”，生成独立的 `MediaSail 接入.md` 快照并复制文件；下拉提供复制文字与修改文件名，名字记住、扩展名固定。网页版仍复制文字。
- 附件是简短接入卡，与现有 format=connect 文字共用内容。提供本机完整 Skill、发现入口、可直接执行的连接命令，现有轻量 check 及按需资料不变；ZIP 仅备用。
- 只允许当前本地主页面调用 desktopActions.copySkillFile(fileName)，不接受路径、网址或待执行内容。缓存位于当前库 runtime/cache/agent-share，独立快照不覆盖、不自动清理，退出后仍可粘贴。
- 文件复制成功不代表目标收到附件或 Agent 已连接。保留文字备用，名称弹窗沿用未保存编辑保护，不改变完整业务资料或 Agent 自主性。
- 按 matt 逐行为红绿验证；预先确认的测试 Seam 是受限桌面 Interface、真实文件剪贴板及可见界面、接入 HTTP/辅助脚本、真实安装升级。各自只证明其覆盖的行为。
- 验证资源管理器、TRAE/Codex 粘贴（合成资料、不发送消息），无法验证的客户端明确标注；核对中文、空格、自定义名、重复/失败复制、退出重启和较晚粘贴。新旧卡片依最新发现信息接入，记录接入耗时，不承诺18秒。
- 运行统一源码检查、补丁复现及以 v0.5.6 为基线的 Standards/Spec 双轴审查。完成隔离0.5.6→0.5.7升级、资料和偏好保留及两次重启。
- Windows x64 0.5.7 同频道发布：草稿五资产核验后正式发布，保留历史文件；旧版能发现、新版显示最新。日常安装与资料库不操作。

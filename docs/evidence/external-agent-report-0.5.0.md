## 本月判断

在这3条记录中，「工具清单」贡献最多收藏与触达，「新手运营检查表」的互动率最高，两者更贴近画像“面向新手的内容运营方法、提高收藏与有效互动”的目标。「每日碎片」在相同触达量下的收藏与互动明显较少，可以优先改写成具体运营问题的解决过程，再做验证。

这是一组小样本观察，不足以证明稳定的爆款规律或内容支柱的长期优劣。建议先用4条成对内容验证“检查表”和“工具清单”的不同价值，再决定长期内容配比。现有评论数只能作为互动代理指标，不能证明评论是否有效。

## 指标核对与口径

已调用 MediaSail 保留的 `skill-social-performance-review/scripts/review.py score`，使用原始JSON直接计算，完整返回保存在 `assets/业务计算结果.json`。另以独立算术复核总量与比例，结果一致。

- 互动数＝点赞＋评论＋收藏＋分享，属于互动次数，不能等同于互动用户数。
- 三篇的互动率分母均为 reach；脚本通用规则为 reach → impressions → views。本次没有混用分母。
- 脚本“平均互动率”为逐帖互动率的算术平均；汇总互动率为总互动÷逐帖reach合计，两者分别报告。

- 缺失字段保持缺失，不补为0；本次四类互动字段完整，分享中的0是原始明确值。impressions、views未提供。

**收藏与触达：工具清单。** 获得全部收藏的65.36%（100÷153）、全部reach的50%。它与检查表的收藏率同为5%，收藏翻倍伴随reach翻倍，不能据绝对收藏数判断工具内容本身的收藏效率更强。“可查、可复用的工具资料适合新手”是由标题与定位得到的解释假设，需阅读正文与评论验证。

**互动效率：新手运营检查表。** 与工具清单同为180次互动，但reach为其一半，所以互动率达到18%；评论率2%，是工具清单的4倍。这支持优先验证“可执行方法能引出具体问题”的方向；尚未取得评论正文，不能把20条评论全算成有效讨论，也不能证明开头或CTA是原因。

**低表现个案：每日碎片。** 在与检查表相同的1,000 reach下，仅15次互动、3次收藏，互动率1.5%、收藏率0.3%。方法与工具两条合计只占75%的reach，却贡献96%的互动和98.04%的收藏。该观察支持优先把泛日常改写为“一个新手难题＋操作步骤＋结果复盘”的小实验；不足以永久删除日常支柱，更不能推断账号限流。

**格式与开头。** 全部只是“图文”标签，未区分单图、轮播或页数，没有视频对照，不能判断哪种格式更优。未提供文案首句、封面、正文和标签，本次跳过Hook、结构、视觉与关键词打分；标题仅用于选题假设。

**节奏。** 记录为9月3日、10日、17日，间隔各7天；现有文件中18—30日没有记录。这是记录空白，未核实是否实际断更。没有时刻与排期，不能判断最佳发布时间或排期执行率。

## 内部评分如何看

脚本返回7.5/10，仅用于该经验公式的参考。本次只启用粉丝增长与最佳帖子两个维度，原权重各20%，归一后各50%：粉丝增长10分、最佳帖子5分，合计7.5分。缺少基准、计划与上月触达的维度未参与。

粉丝维度的实现以“当前粉丝减变化量”近似月初基数，因而隐含前述时点假设；不能把10分理解为已证实的增长质量。最佳帖子先按收藏取「工具清单」，再以其互动率相对全月均值评分，因此它不等同于最高互动率帖子的分数。

脚本的逐帖engagement_score为170、110、14，采用点赞×1＋评论×2＋分享×3（浏览×0.1，本次浏览缺失不贡献分数），不含收藏；本报告依据画像目标优先看收藏与评论，不将该分数当作小红书官方爆款分。

脚本明确提示：缺基准或互动率，跳过基准维度；本月帖子不足5条，结果可能不具统计意义。3条样本时，脚本Top3包含全量、bottom3返回空；本报告的低表现判断来自逐帖指标对照，不把空数组解释为没有低表现内容。

# MediaSail 0.5.3

取消资料迁移，改为安装后的首次启动直接选择资料库。0.5.2 的旧插件目录链接或失败迁移记录不再阻塞启动，旧资料留在原处，不扫描、复制或删除。

- 本次升级重新选择一次，后续更新沿用选择；安装器只选择程序位置。
- 空目录建立新库，已有有效 MediaSail 资料库直接打开；普通非空目录拒绝覆盖，选择失败可重选。
- 设置保留“打开资料库”和“更换资料库”。切换不搬文件，继续检查未保存编辑与运行任务。
- 未选库时明确尚未连接，选库后更新 Agent 连接路径；首页、业务能力、更新和 AitoEarn 沿用。

**旧资料原地保留，不会自动带入新库；新库需要重新配置画像和登录账号。** 已选磁盘不可用时恢复磁盘或重新选库，软件不会悄悄创建空库。

Windows x64 安装包、源码、差量索引与校验文件随本版本提供；历史 Release 保留。未配置 Windows 代码签名。

验证范围及实际结果见 [0.5.3 验证记录](https://github.com/jerryrenjianxing-sys/MediaSail/blob/main/docs/VERIFICATION-0.5.3.md)。

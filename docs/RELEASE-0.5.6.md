# MediaSail 0.5.6

本版统一编辑保护和画像版本核对，继续沿用当前资料库、首页与业务能力。

- 画像、归档、选题、日历、账号表单与画像配置统一处理未保存编辑；切页、切画像、退出和安装更新前核对，取消后保留草稿。
- 画像文件增加版本信息。外部修改后拒绝旧版本保存，展示最新内容供核对；公众号回写冲突时保留采集结果。
- 新增统一源码检查入口、开发约定和业务词汇；源码包包含开发说明。
- 旧画像、项目、方法、登录资料和历史原位保留。资料库选择、默认浏览器 AI 发布和更新机制沿用现状。

源码检查、打包界面回归与隔离 Windows 0.5.5 → 0.5.6 真实升级均通过，连续两次重启后资料仍在。升级保留原安装位置、资料库选择、自定义文件和合成登录资料。

Windows x64 完整安装包约 252 MiB。可在设置中检查更新，或从本版本下载 `MediaSail-0.5.6-win-x64-Setup.exe`；校验值见 `SHA256SUMS.txt`。实测范围、截图、录屏和记录见 [验证记录](https://github.com/jerryrenjianxing-sys/MediaSail/blob/main/docs/VERIFICATION-0.5.6.md)。未使用真实账号公开发布。

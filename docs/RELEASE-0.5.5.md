# MediaSail 0.5.5

AI 发布改为默认浏览器中的 AitoEarn 官网入口，沿用用户自己的浏览器、登录状态和官方扩展流程。

- 点击侧栏“AI 发布”打开官网当前有效中文入口 https://aitoearn.cn/zh-CN，不再内嵌网页、自动上传素材或创建草稿。
- 从内容库打开项目文件夹，从项目成品文件复制正文，再在官网选择图片、视频及封面，检查顺序、账号、平台和排期后发布。官网不会直接读取资料库；实际发布结果不自动回写，按结果登记本地记录。
- 旧 AI 发布记录和登录分区原位保留，不搬 Cookie、不删除资料、不自动续传或重试。设置的历史存档入口可打开旧记录目录；旧发送面板中未回存项目的正文可能只在该记录内。结果未明的草稿先到官网原账号核对，避免重复。
- MediaSail 原生平台登录、账号采集、发布和业务工具保留；内容库分类与编辑、Agent Skill、资料库位置、首页、主题及更新方式继续沿用。

Windows x64 完整安装包、源码、差量索引、更新索引和校验文件随版本提供，历史 Release 保留。发行包未配置 Windows 代码签名。具体测试范围与结果见 [0.5.5 验证记录](https://github.com/jerryrenjianxing-sys/MediaSail/blob/main/docs/VERIFICATION-0.5.5.md)。

# MediaSail 0.5.4 验证记录

## 变更与兼容

内容库按用途查看项目，增加标题／目录／摘要／标签搜索、画像／平台／形态／阶段组合筛选及归档编辑。分类保存在原 `.easel.json` 的可选 `category`，不移动文件；旧项目缺少用途时保留为未分类。归档阶段仍为原 `draft/ready/published`，界面显示草稿、已就绪、已标记发布，不能当作实际发布凭据。

登记接口和 CLI 使用增量修改、原始字节版本摘要、同目录唯一临时文件、fsync 和原子替换。HTTP 同项目写入串行，保存前再次检查外部修改；任意外部文件编辑器不共享进程锁，这属于乐观冲突检查，不宣称任意直接写入具有数据库级事务保证。

用户修改过的 Skill 和业务文件继续按原升级规则保留；双方都有更新时保存两份并提示合并。0.5.3 选库记录沿用，本版不重新选择、不迁移资料，也不改变安装标识和账号位置。

## 独立 Agent 与同一内容库

另一位 Agent 从本次复制说明读取发行包 Skill、连接信息和资料路径，使用真实业务 Python、画像及登记接口，完成以下合成任务；主智能体再独立核对物理文件、API 和打包界面：

- 找到合成咖啡品牌画像，登记两个样本并运行 tracker，核对粉丝从 100 到 125（+25、25%），累计获赞从 180 到 230（+50、27.78%）。保留仅两个点的样本警告，不据此预测或归因。
- 创建一个 creation/draft 图文项目，保存正文和分镜；创建一个 analysis/ready 复盘报告项目。两个项目在各自用途筛选下均可见，三个成品正文与真实文件相同。
- 通过新接口只修改报告摘要和标签，其他十个字段、步骤及成品清单保持；使用旧版本再提交得到 409，文件哈希保持。
- 更新画像经验并读回，保留原合成样本及其他五个维度内容；画像文本按 CRLF/LF 与尾换行归一比较，未声称该既有接口逐字节保留换行。

## Windows 真实安装升级

[完整验收通过](https://github.com/jerryrenjianxing-sys/MediaSail/actions/runs/38893130755)：一次性 GitHub Windows 先安装哈希固定的官方 0.5.3，实际首次选择中文空格资料库，保存合成画像、成品、平台资料位置标记、界面配置及 AitoEarn Cookie／发送记录。保留安装登记，使用正式候选安装包及原更新参数 `/S --updated --force-run`，更新时不传 `/D` 覆盖原路径。

安装器真实退出码为 0，新版自动打开并服务就绪。程序路径和登记保持，没有默认目录旁装；资料库位置与身份不变，没有再次选择；十个固定文件在编辑前字节相同。合成 AitoEarn 会话、界面主题、当前画像及新版安装器缓存／版本凭据均核对通过。新接口只补分类和摘要，其他登记及成品保持；之后连续两次正常退出重启通过，没有退出提示需要测试脚本自动确认。

该轮候选安装观察耗时 167.067 秒，0.5.3 基线安装约 113.635 秒；这是临时 Windows 和测试观察器的结果，不是用户本机安装基准或更新下载测速。安装验收使用 GitHub 已核验文件直接运行真实 NSIS；原客户端发现新版另在正式发布后核对，不把两者合称为下载全链路测速。

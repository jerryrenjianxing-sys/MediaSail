# MediaSail 0.5.13 验证记录

状态：候选开发与验收中，尚未正式发布。需求依据为 [SPEC-0.5.13](SPEC-0.5.13.md)，审查基线为 `v0.5.12`。

## 已执行

- 原始 Windows 环境块包含大小写重复代理变量时，旧实现复现重复键异常；Win32 环境块修复后通过。覆盖无代理、单大写、单小写、冲突大写优先、中文参数及诊断输出。
- 真实命名管道与 Windows PowerShell 5.1 客户端验证身份、资料库、请求去重、并发提交、查询及退出等待；最终回执写入失败从无限 pending 修复为结果未知，不重放。
- 可见旧工具抽屉覆盖 1/1.25/1.5 渲染比例、鼠标/键盘、滚动、焦点及未保存取消；打开关闭前后主区宽度和滚动位置一致。这是渲染比例验证，实际 Windows 显示设置另记。
- 中文业务 HTTP 响应声明 UTF-8，读回与写回一致。
- 统一源码检查通过：131 Node 测试、126 Python 测试（其中一个文件符号链接用例因主机权限跳过）、前端类型/构建、45 路径接口资料及固定上游补丁复现。
- 独立测试桌面实例通过新入口连接专用浏览器；WorkBuddy 5.9.3 经首页实际粘贴 MD 附件，完成连接、已登录后台只读、原始观察/截图、账号观测登记和报告登记，HTTP 读回成功。没有修改宿主代理、Job 限制或日常资料，未公开发布。浏览器缺少协作上下文时按工具回执正常同步再继续；缺项保留 null，不混算不同来源历史。真实账号资料不进入源码或公开证据。
- 实际 Windows 打包程序使用 1280×800/100%、1440×980/125%、1600×1000/150% 应用缩放，验证主区宽度、滚动、筛选及焦点稳定，并保存浅深色截图。没有更改整机 Windows 显示设置；此项不宣称覆盖不同显卡/系统 DPI 的所有差异。

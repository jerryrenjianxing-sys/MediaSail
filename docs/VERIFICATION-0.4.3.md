# MediaSail 0.4.3 验证记录

本版统一 MediaSail、MediaFlow 与 Media Deep Researcher 的首页设计语言。
软件启动后进入全宽 Agent 首页，左侧「控制台」进入原有工作台，右侧
「复制 Skill」继续提供现有接入说明。首页保留 MediaSail 紫色 Logo 和产品文案。

记录日期：2026-10-15（北京时间）。首页预览与最终版本号为 0.4.3 的独立
Windows 应用包均已完成隔离验证；安装器资产及 GitHub 发布核对另列于文末。
预览沿用 0.4.2 版本号，历史预览证据不冒充本次正式版本包结果。

## 本次变更

- 默认显示全宽 Agent 首页，首页不显示控制台侧栏；主按钮与页脚入口均可进入控制台。
- 控制台保留原有工作台、对话、技能库、内容库、AI 发布、账号、画像与设置。
  侧栏「连接 Agent」返回全宽首页；首次画像推荐在进入控制台后显示。
- 根 App 保持挂载，切换首页与控制台时保留聊天状态，并允许正在接收的回复继续完成。
- 首页复用同系列产品的标题、留白、按钮、Agent 图标滚动带和页脚。
  亮暗切换使用按钮中心圆形扩散，支持快速连点、切换中导航和减少动态效果偏好。
- 首页与控制台共用既有 `easel_theme` 偏好和桌面 UI 状态存储；未主动选择主题时跟随系统。
  首页与控制台继续共用更新横幅、现有更新窗口和本次运行的关闭状态。

本次不增加业务 HTTP 或桌面 IPC 接口，不改动 Skill 内容、模型和平台发布流程，
不迁移安装标识、用户数据目录、素材、画像或账号登录分区。
历史聊天及用户资料不做品牌文字替换。

覆盖的实际行为：

- 未设置主题时跟随系统变化，主动选择后优先使用用户偏好；Agent 图标暂停、继续与减少动态时静态显示。
- 正常及 1100×700 内容窗口的浅色、深色页面；Electron 页面缩放 125% 和 150% 下无横向溢出。
  这里改变的是页面缩放，**不是 Windows 系统 DPI 验收**；原始截图环境报告 devicePixelRatio 为 2。
- 首页与控制台显示同一更新状态，打开原更新窗口；关闭横幅后经过页面切换、刷新、托盘隐藏及恢复仍不再显示，

# MediaSail 0.5.11：采集完整性与有据分析

依据用户 2026-11-03 确认：采集器和 Skill 一起修，缺项及失败原因明确，Agent 能自主继续补抓，不增加固定执行链，结论有证据，测试通过后发布原 GitHub 更新频道。基线为已发行 v0.5.10。

复现素材仅用于定位，不将他人账号、作品正文、登录资料或原始会话发行。回归样本为合成文字与数字。记录表明首次接口已核验账号但缺粉丝数、作品数及列表，后续同接口仍缺项，临时浏览器探针才读到作品；不能认为该用户需要额外授权，也不能把粉丝指数当作粉丝数。

实现保留旧字段，补充采集状态、缺项、分项原因、来源、样本覆盖和可选择的只读补查线索。抖音作品读取等待真实内容或明确空态，兼容可读页面文字及延迟加载，保留已取得的部分结果；可选样本上限不代表全量。粉丝指数独立表示。登录验证与采集完成分别解释，未知不填零、不污染正常历史。其他原生工具、发布、首页、MD 接入、资料库与安装标识沿用。

管理页筛选总数独立放在 notesCoverage.total，旧 posts 沿用账号概览口径；不将新旧口径混入增长计算。仅计数占位0不是明确空态；重绘、后续失败仍保留先前已读取的部分内容。字段来源随实际页面记录，包括概览之外的粉丝子页及作品页。

Skill 以任务相关的证据缺口触发参考资料，给候选来源、现有工具与资料锁用法，Agent 自主判断是否补查、重试或请求协助；连接不变成全量采集，不设每轮流程。观察、推断、假设及适用时间/账号/口径分开，来源不可读不推出整个平台没有数据。

验证沿用已确认的脚本/CLI、HTTP、可见界面、独立 Agent 及真实隔离安装 Interface。只在外部浏览器/网络等 Seam 模拟；源码检查、补丁复现、matt Standards/Spec 双轴审查及隔离 0.5.10→0.5.11 升级、两次重启通过后发布。保留历史版本，不覆盖日常安装或资料库，不使用真实账号公开发布。

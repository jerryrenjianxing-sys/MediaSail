# MediaSail 0.5.2：统一资料库与创作者后台核验

**当前为未正式发布的候选说明。正式下载仍是 0.5.0，0.5.1 历史草稿保留。** 安装包、真实升级及发布完成后由发布验收补充结果，不能把源码测试视作已安装成功。

- 软件与外部 Agent 使用同一资料库：画像、素材、成品、方法、业务工具和可写 Skill 集中管理；设置显示实际位置，支持迁移及切换已有资料库。旧资料先复制核验，原目录保留；异常时停止切换，不新建空库覆盖原状态。
- 外部调用每次追踪最新连接文件，核对实例与资料库身份，使用当前真实路径和端口。离线仍可阅读资料及执行本地业务计算，不新增每轮固定协议或创作工具限制。
- 修复抖音创作者后台核验：成功、明确未登录与未知错误分开显示；手动检查绕过缓存。登录关闭并重开确认保存后才报告成功，共享资料锁避免扫码、采集和发布相互争用。
- 新分析快照记录有效账号和来源；不同账号、不同来源及无归属旧记录不混算增长。缺失值保持缺失，失败保留上次展示及采集时间。data-tracker 修正不同平台基线混用。
- 保留用户修改的方法、脚本和 Skill；与新版发生冲突时保留两份并提示。修复缺失的业务依赖，恢复真实 Windows 调用说明。
- 沿用原自动检查、可关闭横幅和手动下载安装。缓存随资料库管理，只复用通过校验的软件缓存。AitoEarn 内嵌页面、独立会话、发送面板与草稿流程保持现状。

不增加内置聊天、OpenClaw、模型执行器或远程命令服务。安装标识、原平台资料和历史 Release 保留；卸载默认保留用户资料。真实平台登录、后台采集和公开发布仍以指定账号验收为准，候选测试未进行真实公开发布。

当前检查及待完成项目见 [0.5.2 验证记录](VERIFICATION-0.5.2.md)。

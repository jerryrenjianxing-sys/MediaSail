# MediaSail 0.5.2：统一资料库与创作者后台核验

Windows x64 完整安装版。沿用现有安装标识和更新频道，保留历史 Release 与 0.5.1 草稿。

- 软件与外部 Agent 使用同一资料库：画像、素材、成品、方法、业务工具和可写 Skill 集中管理；设置显示实际位置，支持迁移及切换已有资料库。旧资料先复制核验，原目录保留；异常时停止切换，不新建空库覆盖原状态。
- 外部调用每次追踪最新连接文件，核对实例与资料库身份，使用当前真实路径和端口。离线仍可阅读资料及执行本地业务计算，不新增每轮固定协议或创作工具限制。
- 修复抖音创作者后台核验：成功、明确未登录与未知错误分开显示；手动检查绕过缓存。登录关闭并重开确认保存后才报告成功，共享资料锁避免扫码、采集和发布相互争用。
- 自动采集的增长只比较同平台、同有效账号、同来源的数据；拿不到稳定身份时仍展示当前指标，明确暂不能比较，不写正常快照。缺失值保持缺失，失败保留上次展示及采集时间，旧历史不重写。data-tracker 修正不同平台基线混用。
- 保留用户修改的方法、脚本和 Skill；与新版发生冲突时保留两份并提示。修复缺失的业务依赖，恢复真实 Windows 调用说明。
- 沿用原自动检查、可关闭横幅和手动下载安装。缓存随资料库管理，只复用通过校验的软件缓存。AitoEarn 内嵌页面、独立会话、发送面板与草稿流程保持现状。

旧版升级后可选择资料库位置，默认推荐“文档/MediaSail资料库”；也可稍后继续使用旧位置。迁移完成仍保留旧目录，请在确认资料齐全后自行决定是否清理。安装包 273,956,517 字节（约 261.26 MiB），不含用户个人资料。

不增加内置聊天、OpenClaw、模型执行器或远程命令服务，卸载默认保留用户资料。真实抖音扫码后的关闭重开、只读采集及资料迁移已在独立测试库验证；没有公开发布内容，也未使用真实 AitoEarn 账号上传或建草稿。

安装、回滚、业务和更新链路的结果及边界见 [0.5.2 验证记录](VERIFICATION-0.5.2.md)。

## 行为反馈

- 桌面复制 Interface 在功能缺失时失败；实现后验证文件附件、UTF-8 中文与独立快照。
- 非法路径参数、缓存目录链接、异步读取期间服务状态变化、重复复制均先复现失败，再完成保护并通过。
- 接入 HTTP Interface 原来缺完整连接命令，红测复现后补全；本机文件优先，ZIP 仅作备用。
- 所有后续源码、真实剪贴板、客户端粘贴和安装验收结果按实际执行补充。代码检查不代替实际客户端兼容与安装结果。

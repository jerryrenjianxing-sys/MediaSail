# MediaSail

<img src="branding/MediaSail-app-icon.png" alt="MediaSail" width="112">

面向外部 Agent 的运营知识与内容工作台。MediaSail 保存画像、历史表现、运营经验、素材与成品，提供账号采集、业务统计和发布能力；由你熟悉的 Agent 自主研究、解读、策划、创作与回存。

**[下载 Windows x64 正式安装包](https://github.com/jerryrenjianxing-sys/MediaSail/releases/latest)** · [0.5.6 更新说明](docs/RELEASE-0.5.6.md) · [验证记录](docs/VERIFICATION-0.5.6.md) · [本机真实升级记录](docs/LOCAL-UPGRADE-2026-10-15.md) · [更新机制](docs/UPDATES.md)

## 使用与连接 Agent

从 Releases 安装最新 Windows x64 完整安装包。首页左侧进入控制台，右侧复制 Skill，粘贴给同一台电脑上支持本地文件和工具的 Agent。已有首页布局、紫色品牌、Agent 图标和亮暗动画保持一致。

当前源码为 **0.5.6**，候选验收及发布状态见验证记录。本版统一未保存编辑保护，为画像文件增加版本冲突核对；保留用户草稿并展示外部最新内容。AI 发布继续用默认浏览器打开官网。内容库分类、搜索、筛选和归档编辑、直接选库及现有业务沿用，旧项目与历史资料原位保留。

软件内置精简 Python 与业务依赖，不需要配置聊天模型；不再内置 OpenClaw、聊天、独立 Node、FFmpeg、专用浏览器或通用创作模型。账号网页操作使用已配置浏览器，或检测本机 Chrome、Edge；缺浏览器只影响对应操作，不阻止软件启动。

画像建档、编辑、账号数据回写、采集、统计、内容库、选题、日历、平台登录和发布继续提供。画像增强、深度解释及策略创作由外部 Agent 根据完整专业方法完成。Skill 介绍真实资料、路径和工具，不规定 Agent 用什么创作工具，不要求每轮执行固定流程，也不自动安装进其他 Agent 的全局配置。

完整 Skill 随软件提供，连接文件兼容端口变化与中文路径。现成业务计算可通过内置 Python 调用；通用创作环境由 Agent 自选。成品按项目目录及元数据登记，用途为创作内容、分析报告或参考资料；搜索标题、目录名、摘要和标签，不做正文全文搜索。分析经验可更新回画像。内容库和画像页面可刷新查看外部更新；未保存编辑不会自动覆盖。阶段中的“已标记发布”只是本地归档标记，不代替真实发布记录。

0.5.2 的账号页面区分“已验证”“需要登录”和“暂时无法核验”，显示检查时间。抖音登录用于创作者后台，用户默认浏览器的普通主页登录不能替代核验。手动校验绕过缓存；采集失败显示原因并保留上次结果和原采集时间，不把缺失填成零。自动历史增长只比较同平台、同有效账号、同来源；无法核对稳定身份时仍展示当前有效指标，明确不能比较，不写正常快照。旧无归属资料保留，不自动归给当前账号，也不重写旧 JSONL。手工 tracker 按用户指定画像、平台和口径管理，沿用原公式。

## AI 发布

点击侧栏“AI 发布”，使用用户默认浏览器打开 [AitoEarn 中国站](https://aitoearn.cn/zh-CN)。从内容库打开项目文件夹，从项目成品文件复制正文，在官网自行选择图片、视频及封面，检查顺序、账号、平台和排期后发布。用户与外部 Agent 仍在同一资料库准备素材，官网不能因知道目录位置就直接读取磁盘或自动选中文件。

AitoEarn 的登录、浏览器扩展、额度及平台支持由官方服务负责；默认浏览器使用自己的登录状态，可能需要重新登录。MediaSail 不迁移旧 Cookie，不调用 AitoEarn 上传、草稿或发布接口，也不会自动读回网站发布结果。按官网实际结果补充本地发布记录；项目的“已标记发布”不代替发布事实。MediaSail 原生的平台登录、采集、发布及业务工具保留。

旧版 `runtime/aitoearn/imports.json` 和 `runtime/Partitions` 原位保留；可从设置的历史存档入口打开旧 AI 发布记录目录。发送面板中尚未回存项目的标题、正文或素材顺序可能只在旧记录中。旧任务不会自动续传或重试，结果未明的草稿先到原账号官网核对，避免重复创建；保留记录不代表旧任务已在云端取消。

## 更新与旧程序清理

主页面就绪后约15秒自动检查GitHub新版，显示可关闭横幅；设置、侧栏和托盘也能检查。用户选择下载、校验、重启安装，不自动下载或安装，也不发行过渡版。

升级沿用原安装标识和目录，先正常卸载旧程序，再安装新程序，移除旧的大型运行环境。卸载失败即停止并记录日志，不大范围删除目录兜底。新版启动后只清理本软件管理且能识别版本的过期更新安装包，保留当前差量更新缓存。GitHub旧Release和用户自行保存的安装包不删除。

2026-10-15 已在本机 Windows 原生环境完成 0.4.3 → 0.5.0 更新、旧运行环境清理、两次正常重启及数据核验，最终安装位置保持不变。首轮由测试工具隔离视图引起的旁装已清理，不能作为普通 Windows 启动的缺陷结论。未因此额外发布版本。

主分支另有**未发行的 0.5.1 候选**，用于验证人为缺少安装登记时的恢复能力：核对官方旧程序身份，实际卸载前恢复必要登记，失败时回滚。该候选仍为 GitHub 草稿，不是最新正式版，不会被软件的检查更新发现；[候选验证记录](docs/VERIFICATION-0.5.1.md)。

### 直接选择统一资料库

安装器只选择软件位置。0.5.3 首次启动重新选一次资料库，以后更新沿用选择。空目录建立新库；已有有效 MediaSail 库直接打开；普通非空目录不覆盖。默认建议“文档/MediaSail资料库”，可选择其他本地专用目录。设置提供“打开资料库”和“更换资料库”；更换前保存编辑、结束软件任务并暂停外部 Agent 写入，切换仅改变位置，不搬运文件。

**旧资料原地保留，不会自动带入新库；新库需要重新配置画像和登录账号。** 旧版失败的迁移记录只保留作记录，不再执行，不扫描旧工作区或插件链接。选定磁盘不可用时显示恢复或重新选库入口，不自动创建另一份空库。

    MediaSail资料库/
      workspace/              配置、画像、素材、成品、分析、运营方法与业务脚本
        profiles/             六维画像与经验
        outputs/              项目、成品、系统分析与发布记录
        skills/               保留的业务工具与完整专业方法
      agent-skill/mediasail/   可写 Skill、参考资料与连接辅助脚本
      runtime/                平台浏览器资料、界面状态、历史存档、日志与更新缓存
        agent-connection.json 当前实例及全部真实路径，无密钥

软件与 Agent 直接使用同一份 workspace。用户修改的方法、脚本与 Skill 保持生效；新版也有修改时保存两份并提示合并。`%LOCALAPPDATA%/ElectronEasel` 保留为兼容旧版的定位入口，发现镜像里的 `connectionFile` 指向当前资料库的正式连接文件。移动位置或端口变化后，辅助脚本会重读并核对实例，不需要另建一套 Agent 工作副本。

新库的平台资料和存档使用 runtime 对应位置；已有库内的旧 AitoEarn 分区与发送记录保留，不再作为新版本的登录或任务来源。旧 AppData 资料和之前的库不导入、不搬动、不删除；直接打开已有有效库时使用该库自己的资料。卸载默认保留资料库和旧数据，不删除用户自行保存的安装包。

旧聊天停止续跑，可从设置打开存档目录。用户修改的脚本、素材及已进入工作目录的旧演示内容不会为了瘦身被清除。关闭窗口留在托盘；主动退出只结束软件自己的服务和业务任务，外部Agent任务由其环境负责。

## 开发与构建

固定基线：[ZJU-REAL/Easel fb80ae6](https://github.com/ZJU-REAL/Easel/tree/fb80ae6dd6fc26f5553efcb293ee6d93ef253f02)。完整修改见 patches/easel-desktop.patch；知识整理在打包暂存区执行，不覆盖用户资料或原上游知识源。源码包包含对应源码、前端、构建脚本及依赖锁。

Windows构建机需要 Git、uv、PowerShell 和用于引导的Python。执行 scripts/build.ps1：获取固定基线、应用补丁、准备精简业务环境、构建前端、整理完整方法及业务工具、核对清单，再构建NSIS安装包。独立Node只作为构建工具，不进入发行运行环境。

| 部件 | 版本 |
|---|---|
| MediaSail 当前源码 | 0.5.6；0.5.1 历史草稿保留 |
| Electron / electron-builder | 44.7.0 / 26.15.3 |
| electron-updater | 6.8.9 |
| Python | 3.11.15 |
| 构建用Node | 24.21.0 |

开发前阅读 [AGENTS.md](AGENTS.md) 与按需的 [开发方法](docs/DEVELOPMENT.md)，使用用户指定的 mattpocock-skills；业务术语见 [词汇表](GLOSSARY.md)。准备锁定依赖后执行 npm run check，统一验证 Node、Python、前端、接口资料和补丁复现。检查不回写接口资料或补丁，需更新时显式运行导出脚本并审查差异。

业务依赖固定于 requirements-business.lock，实际组件及许可证见 licenses。npm run dist生成安装包、blockmap和latest.yml；scripts/source-bundle.py创建匹配源码包，scripts/verify-release.cjs核对校验并生成SHA256SUMS.txt。产物在仓库外 ../../outputs/MediaSail/release-0.5.6。包内验收与真实安装升级另行执行。

运行打包版UI验收时使用main分支最新测试脚本，同时隔离`EASEL_DESKTOP_DATA`与`LOCALAPPDATA`；测试统一资料库时另用专用定位目录和资料库路径，避免读写日常安装。更新缓存使用当前库的 runtime；安装器独立暂存本次新安装包，在选库后核验领用，不导入旧库缓存。真实安装结果见对应版本验证记录，单元测试不代替安装验收。

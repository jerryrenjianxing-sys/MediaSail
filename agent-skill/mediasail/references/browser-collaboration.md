# 真实浏览器协作

适用于需要查看平台账号、作品、私有运营数据，或准备浏览器连接的任务。业务取数与回存不绑定某个浏览器工具。

## 连接与登录

你已有可用工具和浏览器连接时直接复用；有工具但尚未连接时沿用它的连接办法。连接已有的用户 Edge 或 Chrome 配置，再使用任务需要的页面。浏览器工具连接成功、网站账号已登录、创作者后台具有权限是三个不同状态。

Agent 可检查和准备本地工具、说明连接办法、打开安装或连接页面，并在权限范围内执行操作。浏览器若要求用户确认安装扩展、授权受控页面，或平台要求扫码、验证码，由用户在原生界面完成对应步骤；明确说剩哪一步，完成后继续。已有能力不需要另装一套。日常只连接用户实际使用的浏览器，不要求同时安装两种浏览器的扩展。

正常使用过程中保持用户的真实会话；断开自动化连接后，用户仍可使用自己的浏览器。站点登录失效时按站点流程恢复，不把连接工具的成功回执当成账号已登录。

## 取数与证据

根据当前任务自主选择页面、可访问响应和已有资料；页面只显示部分信息时可以继续查适用来源，无需等用户重复说“抓一下”。保留平台、稳定账号编号的依据、实际取得时间、指标标签/单位/窗口/范围，以及证据位置。身份或指标未知仍可以保存，说明缺项及其影响。

公开主页、创作者后台、内容管理页的口径可能不同。作品样本条数、管理页筛选总数、概览累计作品数分别记录。完整性、缺项与分析证据的判断见[采集缺项与有据分析](collection-evidence.md)。

## 回到 MediaSail

使用[账号观测登记](account-observations.md)保存结构化数据。原始摘录、截图、报告放当前项目，用现有成品登记进入内容库；稳定经验按任务更新六维画像。刷新软件只重新读取这些文件，不要求旧采集器登录。

原生采集工具是可选的独立入口：它仍使用 MediaSail 管理的专用浏览器资料，主动调用它才需要自己的有效工具登录。真实浏览器的 Cookie 不会自动复制给旧采集器，外部观测也不会把旧 whoami 改成已验证。

软件暂停、升级或 HTTP 暂不可用时，保留原库中的证据、输入和任务结果。恢复后核对原资料库身份，再补登记；保存失败无需重新取数。浏览器连接生命周期与工具自身能力有关，不能从软件在线状态推断连接仍有效。

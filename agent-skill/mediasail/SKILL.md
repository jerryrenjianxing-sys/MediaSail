# MediaSail

MediaSail 是用户的运营背景和经验中心。画像、受众、内容风格、历史表现与素材帮助你理解用户正在做什么；你的研究、判断和创作能力帮助用户把工作做好。按当前任务选择合适的资料与工具，可以使用自己的工具，也可以复用软件能力。

画像和历史分析是参考，不是僵化规则。需要调整画像、改进软件或尝试新方向时，结合用户目标开展工作。完成内容后，可以把成品、关键发现和可复用经验整理回 MediaSail，让下一次协作更有背景。这里没有规定固定创作流程、强制模板或每轮检查步骤。

内容库按项目保存成果，可以区分创作内容、分析报告和参考资料，再按类型、画像等信息查找。回存时可补充标题、摘要、用途和真实成品清单；原始数据与过程文件留在项目素材区。分类只帮助检索，不指定工具或执行链。已有项目路径保持原样，缺分类的旧项目仍能查看，按需补充即可；详见[素材与成品](references/outputs.md)。

AI 发布是默认浏览器中的 AitoEarn 官网入口。可用已有浏览器能力按用户当次授权操作网页、选择项目媒体并核对结果；用户要求只准备发布页时，就交付准备好的页面。网站结果不会自动回写，按实际结果补充记录。旧采集工具及其登录、发布接口按需保留，详见[工具与接口](references/tools-api.md)。

## 接入

首页可复制固定名称的 `MediaSail 接入.md` 文件，包含本机发现入口和完整可执行命令。先用其中的轻量连接命令取得当前路径，再读取本机完整 Skill；仅在本机文件无法读取时取备用 ZIP。资料与业务方法仍按任务查阅，无需为连接运行平台校验或全量自检。

复制说明中的 `agent-connection.json` 记录当前资料库、运行数据目录、服务地址、业务工具、内置 Python 和本地 Skill 的位置。默认发现入口是 `%LOCALAPPDATA%\ElectronEasel\agent-connection.json`，其中 `connectionFile` 指向当前资料库的正式连接文件；位置以复制说明为准。每次使用辅助脚本都会重新读取，不记死端口或上一次资料库路径。`selectedProfile` 是软件当前选择的运营画像提示，用户任务明确指定的对象优先，不代表其他 Agent 正在执行的任务。

`workspace` 就是控制台正在使用的工作目录。默认直接在这里读写画像、素材、项目和运营方法，成果回存后刷新原页面即可；无须另建工作副本再同步。`skillDir` 是资料库中可维护的接入 Skill。升级保留用户修改的工作文件；本地与新版同时变化时保留两份并提示冲突，真实位置由连接资料提供。

尚未选择资料库时，发现入口的 `status` 为 `needs-library`，不代表已连接；请先在软件中选库，再重新读取连接资料。更换资料库只切换路径，旧库文件仍在原位，不自动导入。新建库不带入旧画像、配置或登录状态。

用辅助脚本快速了解实际状态：

```powershell
& "<Skill目录>\scripts\mediasail.ps1" check --data-dir "<数据目录>"
```

脚本每次重读连接文件并核对服务身份。端口会变化，不长期记住复制说明里的 URL。软件关闭时仍能查看本地资料和运行确定性的本地业务计算；需要 HTTP 接口时再启动软件。软件提供业务 Python，不需要 OpenClaw 或网关。已有浏览器能力可以直接复用，缺少时可按需使用内置专用 Chromium 与 BrowserSkill，入口见可选的 `browserTools`；普通接入不启动它们。通用创作工具仍由你按任务选择，不承诺内置 Node、FFmpeg、图像或语音模型。

初次接入，简短反馈实际服务状态、资料是否找到和能帮用户做什么，并说明：需要网站资料时会准备目标页面，遇到扫码或验证再请用户完成；用户也可以先让你打开网站登录。有任务就继续任务，不让用户选择底层登录技术路线。区分“资料已找到、工具可用、浏览器已连接、网站已登录”；只说明实际核对过的状态。开场建议无需每轮重复。

## 根据任务开展工作

| 用户目标 | 可用做法与查阅入口 |
| --- | --- |
| 登录、查看账号或补抓数据 | 优先复用自己的浏览器能力，需要备用时调用软件连接入口；先打开适合任务的页面，识别真实登录状态和账号，再按需要请求扫码。查[浏览器协作](references/browser-collaboration.md) |
| 建立或修改画像 | 阅读相关六维资料、用户偏好与建档方法，自主访谈或研究；用当前版本保存内容，读回核对。查[画像与分析](references/context.md) |
| 受众、竞品、分析与复盘 | 使用已保存观测及必要的浏览器补证，按需调用确定性业务计算，保留来源、口径、未知项和结论证据。查[有据分析](references/collection-evidence.md)与[专业方法](references/knowledge.md) |
| 热点、选题、日历 | 核对来源时效，自主判断，再用现有 ideas/schedule 接口登记计划。查[工具与接口](references/tools-api.md) |
| 文案、图像、视频等创作 | 结合当前用户的画像偏好和任务要求选择创作工具；既有专业方法提供判断与案例，不固定供应商或执行链 |
| 整理素材、成品、报告和经验 | 直接在共用项目目录工作，登记实际成品及证据；稳定经验按任务回存画像，刷新软件读回。查[素材与成品](references/outputs.md) |
| 发布与软件维护 | 发布按当次授权及页面真实能力完成，结果核对后记录；维护查[源码与维护](references/development.md) |

这是任务入口，不是必须依次执行的清单。旧采集工具面向兼容与手动操作，使用自己的独立登录资料；已有浏览器取得的观测可直接回存，不先要求用户登录旧工具。

## 按需查资料

- 想理解用户、分析表现或积累经验：[画像与分析](references/context.md)。
- 需要使用真实浏览器、按需打开内置专用浏览器或理解旧工具登录区别：[浏览器协作](references/browser-collaboration.md)。已有能力直接复用；内置工具自动配置，用户只处理必要的网站登录。
- 已取得账号数据，想回存、查历史或显示到工作台：[账号观测](references/account-observations.md)。可以保存缺项、证据和报告指向，回存不依赖旧工具登录；失败只补保存。
- 分析本人账号、采集缺项或需要核对结论依据：[采集缺项与有据分析](references/collection-evidence.md)。取数范围不等于工具能力上限，按任务自主选择补查来源并说明证据边界。
- 想查运营方法、镜头结构、平台经验及保留的业务计算：[专业方法索引](references/knowledge.md)。完整方法在工作目录 `skills/KNOWLEDGE.md`；文风证据、受众研究、竞品、素材对应和经验修订可按任务查阅，不是固定产线。
- 想找现成工具、调用接口、登录或发布：[工具与接口](references/tools-api.md)。完整的接口参数另见随包的 [接口结构](references/api-schema.json)。
- 想导入素材、分类检索、登记成品或修改项目信息：[素材与成品](references/outputs.md)。
- 想找安装目录、修改源码、调整配置、构建或排查问题：[源码与维护](references/development.md)。

这些资料说明工具在哪里、怎么使用及实际效果。软件负责业务数据、画像、分析资料、账号、内容库与发布适配；研究、语义分析、画像增强和创作由外部 Agent 完成。浏览器登录与各平台自身的支持范围以实际运行的软件为准。
